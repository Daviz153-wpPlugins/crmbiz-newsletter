# Phase 2: 큐 + Rate Limiting 안정화

> 목표: 100~1,000명 수신자에서도 안정적 발송, 브라우저 응답 지연 없음  
> 기간: 2~3주  
> 전제: Phase 1 완료 (소규모 발송 검증됨)

---

## 목표

Phase 1의 즉시 발송 루프를 WP Cron 배치 큐로 교체합니다.

---

## WP Cron 배치 큐 설계

```
포스트 발행 버튼 클릭
    │
    ├── 즉시: DB에 status=draft 저장
    ├── 즉시: wp_schedule_single_event(time(), 'crmbiz_nl_send_async', [$id])
    └── 즉시: 브라우저에 응답 반환 (멈춤 없음)

[WP Cron 실행 — 다음 방문자 요청 시 또는 서버 크론]
    │
    ├── 수신자 목록 조회
    ├── 25통 배치로 분할
    ├── 배치 1: wp_mail() × 25
    ├── sleep(1)
    ├── 배치 2: wp_mail() × 25
    ├── sleep(1)
    ├── ...
    └── 완료: status=sent, sent_at=now()
```

### 배치 크기 가이드

| SMTP 서비스 | 권장 배치 크기 | 배치 간격 |
|-------------|---------------|-----------|
| AWS SES | 14~25통 | 1초 |
| SendGrid | 50~100통 | 1초 |
| Mailgun | 50~100통 | 1초 |
| Gmail | 5~10통 | 2초 |

설정 페이지에서 조정 가능.

---

## 추가 기능

### 예약 발송

메타박스에 날짜/시간 선택 UI 추가.  
`wp_schedule_single_event($timestamp, 'crmbiz_nl_send_async', [$id])` 등록.

### 수동 발송

발송 이력 페이지에서 `draft` 상태 레코드에 "지금 발송" 버튼.  
관리자가 직접 타이밍 조절 가능.

### 실패 알림

발송 실패 시 관리자 이메일로 알림.  
발송 이력 페이지에서 재발송 버튼.

---

## 성공 기준

- [ ] 100명 발송 시 포스트 발행 응답 지연 2초 이내
- [ ] 500명 발송 성공 (SMTP 한도 내)
- [ ] 예약 발송 정시 동작
- [ ] 수동 발송 동작
- [ ] 실패 시 관리자 이메일 알림 수신

---

## SMTP 서비스 선택 가이드

| 규모 | 추천 서비스 | 비용 |
|------|------------|------|
| ~100명 | Mailgun 또는 SendGrid 무료 플랜 | 무료 |
| ~1,000명 | Mailgun 또는 SendGrid | ~$10/월 |
| ~10,000명 | AWS SES | ~$1/1,000통 |
| 10,000명+ | AWS SES (샌드박스 탈출 필요) | 저렴 |

> **AWS SES 샌드박스 탈출**: AWS 콘솔 → SES → 계정 대시보드 → Production access 요청.  
> 심사 1~2일 소요. 샌드박스 상태에서는 검증된 이메일만 수신 가능.
