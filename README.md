# CRMBiz Newsletter

FluentCRM 연락처를 기반으로 WordPress 포스트를 뉴스레터로 자동 발송하는 플러그인입니다.

## 요구사항

- WordPress 5.8 이상
- PHP 8.0 이상
- [FluentCRM](https://wordpress.org/plugins/fluent-crm/) 2.x 이상 (필수)

## 설치

1. 이 저장소를 ZIP으로 다운로드하거나 릴리즈 페이지에서 최신 버전을 다운로드합니다.
2. WordPress 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 ZIP 파일을 업로드합니다.
3. FluentCRM이 먼저 활성화되어 있어야 합니다.
4. 플러그인을 활성화합니다.

## 주요 기능

- **자동 발송** — 포스트 발행 시 FluentCRM 태그/리스트 기준으로 뉴스레터를 자동 발송
- **발송 모드** — 즉시 발송 / 예약 발송 / 수동 발송 지원
- **배치 처리** — WP Cron 기반으로 1회 50건씩 나눠 발송 (서버 부하 방지)
- **재시도 로직** — 발송 실패 시 최대 3회 자동 재시도
- **오픈/클릭 트래킹** — 이메일 열람 및 링크 클릭 추적
- **수신거부 관리** — HMAC 서명 기반 1년 유효 수신거부 링크 제공, FluentCRM 상태 자동 동기화
- **이메일 암호화** — 수신거부/트래킹 URL에 AES-256-CBC 암호화 적용
- **관리자 알림** — 발송 완료 시 성공/실패 통계를 관리자 이메일로 전송
- **드라이런 모드** — 실제 발송 없이 동작 테스트 가능

## 사용법

### 1. 설정

관리자 메뉴 → 뉴스레터 → 설정에서 아래 항목을 입력합니다.

| 항목 | 설명 |
|------|------|
| 발신자 이름 | 이메일의 From 이름 |
| 발신자 이메일 | 이메일의 From 주소 |
| 드라이런 모드 | 활성화 시 실제 발송 없이 테스트 |

### 2. 포스트 작성

포스트 편집 화면의 **CRMBiz Newsletter** 메타박스에서:

1. **뉴스레터 발송** 체크박스를 활성화합니다.
2. 수신 대상 태그 또는 리스트를 선택합니다.
3. 발송 모드를 선택합니다.
   - **즉시 발송** — 포스트 발행 즉시 발송
   - **예약 발송** — 지정한 일시에 발송
   - **수동 발송** — 관리자가 직접 발송 버튼을 눌러 발송

### 3. 발송 이력

관리자 메뉴 → 뉴스레터 → 발송 이력에서 발송 현황, 성공/실패 수, 오픈율, 클릭율을 확인할 수 있습니다. 개별 수신자 재발송도 가능합니다.

## 데이터베이스 테이블

플러그인 활성화 시 아래 테이블이 자동 생성됩니다.

| 테이블 | 설명 |
|--------|------|
| `crmbiz_newsletters` | 뉴스레터 발송 레코드 |
| `crmbiz_nl_queue` | 발송 대기 큐 |
| `crmbiz_nl_unsubscribers` | 수신거부 목록 |
| `crmbiz_nl_events` | 오픈/클릭/수신거부 이벤트 로그 (90일 보관) |
