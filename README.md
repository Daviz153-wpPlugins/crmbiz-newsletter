# CRMBiz Newsletter

FluentCRM 연락처를 기반으로 WordPress 포스트를 뉴스레터로 자동 발송하는 플러그인입니다.

**현재 버전: 0.9.3**

## 요구사항

- WordPress 5.8 이상
- PHP 8.0 이상
- [FluentCRM](https://wordpress.org/plugins/fluent-crm/) 2.x 이상 (필수)
- [FluentSMTP](https://wordpress.org/plugins/fluent-smtp/) (선택 — 미설치 시 WordPress 기본 메일 사용)

## 설치

1. [릴리즈 페이지](https://github.com/Daviz153/crmbiz-newsletter/releases/latest)에서 최신 ZIP을 다운로드합니다.
2. WordPress 관리자 → 플러그인 → 새로 추가 → 플러그인 업로드에서 ZIP을 업로드합니다.
3. FluentCRM이 먼저 활성화되어 있어야 합니다.
4. 플러그인을 활성화합니다.

업데이트는 WordPress 플러그인 화면에서 자동으로 알림을 받습니다.

## 주요 기능

### 발송
- **자동 발송** — 포스트 발행 시 FluentCRM 태그/리스트 기준으로 자동 발송
- **발송 모드** — 즉시 / 예약(일시 지정) / 수동(관리자 직접 트리거) 3가지 지원
- **배치 처리** — WP Cron 기반으로 1회 50건씩 발송 (서버 부하 방지)
- **재시도 로직** — 발송 실패 시 최대 3회 자동 재시도 후 영구 실패 처리
- **중복 발송 방지** — MySQL `GET_LOCK`으로 동시 Cron 실행 차단

### 이메일
- **오픈/클릭 트래킹** — 열람 및 링크 클릭 이벤트 추적
- **이메일 암호화** — 수신거부·트래킹 URL에 AES-256-CBC 암호화 적용
- **이메일 커스터마이징** — 색상 테마(모던/다크/미니멀 프리셋), 콘텐츠 너비, 대표이미지·날짜·웹보기 링크 표시 옵션
- **시그니처** — 프로필 사진, 이름/직함, 소개 문구 포함 가능, 위치·간격·배경 설정

### 관리
- **대시보드** — 발송 캠페인 수, 성공/실패, 성공률, 최근 30일 추이 차트
- **발송 이력** — 진행 상태, 오픈율, 클릭율 조회, 재발송/취소/삭제 가능
- **수신 거부 관리** — HMAC 서명 기반 수신거부 링크, FluentCRM 상태 자동 동기화, CSV 내보내기
- **관리자 알림** — 발송 완료 시 성공/실패 통계를 이메일로 전송

### 개발/테스트
- **드라이런 모드** — 실제 발송 없이 동작 테스트
- **디버그 모드** — FluentCRM 시스템 로그에 상세 정보 기록
- **테스트 발송** — 설정 페이지에서 특정 이메일로 즉시 테스트 발송

## 사용법

### 1. 설정

관리자 메뉴 → 뉴스레터 → 설정

**기본 설정**

| 항목 | 설명 |
|------|------|
| 발신자 이름 | 수신자에게 표시될 From 이름 (비워두면 FluentCRM 설정 또는 사이트 이름 사용) |
| 발신자 이메일 | From 이메일 주소 (비워두면 FluentCRM 설정 또는 관리자 이메일 사용) |
| 테스트 모드 | 활성화 시 실제 발송 없이 동작 (개발/테스트용) |
| 디버그 모드 | FluentCRM 로그에 상세 정보 기록 |
| 알림 이메일 | 발송 완료 알림을 받을 이메일 (비워두면 WordPress 관리자 이메일) |

**이메일 커스터마이징**

| 항목 | 설명 |
|------|------|
| 색상 테마 | 모던/다크/미니멀 프리셋 선택, 또는 색상 직접 지정 |
| 콘텐츠 너비 | 이메일 본문 최대 너비 (480–800px) |
| 섹션 표시 | 대표 이미지, 최근 뉴스레터 목록, 웹에서 보기 링크, 발송 날짜 표시 여부 |
| 시그니처 | 프로필 사진, 이름/직함, 소개 문구, 사진 위치/간격/배경 설정 |

### 2. 포스트 작성

포스트 편집 화면의 **뉴스레터 발송 설정** 메타박스에서:

1. **뉴스레터로 발송** 체크박스를 활성화합니다.
2. 수신 대상 태그 또는 리스트를 선택합니다 (예상 수신자 수 자동 표시).
3. 발송 모드를 선택합니다.
   - **즉시 발송** — 포스트 발행과 동시에 자동 발송
   - **수동 발송** — 발행 후 관리자가 발송 이력 페이지에서 직접 트리거
   - **예약 발송** — 지정 일시에 자동 발송

### 3. 발송 이력

관리자 메뉴 → 뉴스레터 → 발송 이력

- 발송 상태(대기/발송 중/완료/실패), 수신자 수, 오픈율, 클릭율 확인
- 발송 중인 경우 실시간 진행률 표시
- 개별 캠페인 상세 조회: 수신자 목록, 오픈/클릭 이벤트
- 재발송, 즉시 발송, 취소, 삭제 가능

### 4. 수신 거부 관리

관리자 메뉴 → 뉴스레터 → 수신 거부

- 수신거부 이메일 목록 조회 및 검색
- 직접 추가 / 일괄 해제
- CSV 내보내기

## 데이터베이스 테이블

플러그인 활성화 시 아래 테이블이 자동 생성됩니다.

| 테이블 | 설명 |
|--------|------|
| `crmbiz_newsletters` | 뉴스레터 발송 레코드 |
| `crmbiz_nl_queue` | 발송 대기 큐 |
| `crmbiz_nl_unsubscribers` | 수신거부 목록 |
| `crmbiz_nl_events` | 오픈/클릭/수신거부 이벤트 로그 (90일 보관) |
| `crmbiz_nl_ratelimit` | 수신거부 요청 Rate Limit |

플러그인 삭제 시 모든 테이블, 옵션, 포스트 메타, 예약 이벤트가 자동 삭제됩니다.
