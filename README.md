# CRMBiz Newsletter

FluentCRM 연락처를 기반으로 WordPress 포스트를 뉴스레터로 자동 발송하는 플러그인입니다.

**현재 버전: 1.0.0**

## 요구사항

| 항목 | 최소 버전 |
|------|-----------|
| WordPress | 5.8 이상 |
| PHP | 8.0 이상 |
| [FluentCRM](https://wordpress.org/plugins/fluent-crm/) | 2.x 이상 (필수) |
| [FluentSMTP](https://wordpress.org/plugins/fluent-smtp/) | 선택 — 미설치 시 WordPress 기본 메일 사용 |

---

## 설치 가이드

### 1단계 — ZIP 다운로드

[릴리즈 페이지](https://github.com/Daviz153/crmbiz-newsletter/releases/latest)에서 `crmbiz-newsletter-vX.X.X.zip`을 다운로드합니다.

### 2단계 — FluentCRM 먼저 활성화

이 플러그인은 FluentCRM에 의존합니다. FluentCRM이 없으면 활성화 화면에서 오류가 표시됩니다.

1. WordPress 관리자 → 플러그인 → 새로 추가
2. "FluentCRM" 검색 후 설치 및 활성화

### 3단계 — 플러그인 설치

1. WordPress 관리자 → 플러그인 → 새로 추가 → **플러그인 업로드**
2. 다운로드한 ZIP 파일을 선택합니다.
3. **지금 설치** 클릭 → **플러그인 활성화**

활성화 시 필요한 DB 테이블 7개가 자동 생성됩니다.

### 4단계 — 기본 설정

관리자 메뉴 → **뉴스레터 → 설정**

| 항목 | 설명 |
|------|------|
| 발신자 이름 | 수신자에게 표시될 From 이름. 비워두면 FluentCRM 설정 또는 사이트 이름 사용 |
| 발신자 이메일 | From 이메일 주소. 비워두면 FluentCRM 설정 또는 관리자 이메일 사용 |
| 알림 이메일 | 발송 완료 알림을 받을 이메일. 비워두면 WordPress 관리자 이메일 |
| 테스트 모드 | 활성화 시 실제 발송 없이 동작 (개발/테스트용) |

### 5단계 — 서버 Cron 설정 (권장)

WordPress 기본 WP Cron은 사이트 방문자가 있을 때만 실행됩니다. 트래픽이 적은 서버에서는 예약 발송이 지연될 수 있습니다.

**옵션 A — 서버 Crontab (권장)**

```bash
# wp-config.php에 추가
define('DISABLE_WP_CRON', true);

# 서버 crontab에 추가 (1분마다)
* * * * * cd /var/www/html && php wp-cron.php > /dev/null 2>&1
# 또는 WP-CLI 사용
* * * * * cd /var/www/html && wp cron event run --due-now > /dev/null 2>&1
```

**옵션 B — Action Scheduler (FluentCRM 사용 중이면 자동 적용)**

FluentCRM이 Action Scheduler를 번들하며, 이 플러그인은 설치 시 자동으로 AS Async Runner를 활성화합니다. 별도 설정 없이 WP Cron보다 신뢰성 높게 동작합니다.

## 주요 기능

### 발송
- **자동 발송** — 포스트 발행 시 FluentCRM 태그/리스트 기준으로 자동 발송
- **발송 모드** — 즉시 / 예약(일시 지정) / 수동(관리자 직접 트리거) 3가지 지원
- **배치 처리** — 1회 50건씩 발송 (기본값, `crmbiz_nl_batch_size` 필터로 조정 가능)
- **재시도 로직** — 발송 실패 시 최대 3회 자동 재시도 후 영구 실패 처리
- **중복 발송 방지** — MySQL `GET_LOCK`으로 동시 Cron 실행 차단
- **바운스 자동 처리** — FluentCRM 바운스/스팸 신고 시 수신거부 목록에 자동 등록

### 이메일
- **오픈/클릭 트래킹** — 열람 및 링크 클릭 이벤트 추적
- **이메일 암호화** — 수신거부·트래킹 URL에 AES-256-GCM 인증 암호화 적용
- **이메일 커스터마이징** — 색상 테마(모던/다크/미니멀 프리셋), 콘텐츠 너비, 대표이미지·날짜·웹보기 링크 표시 옵션
- **시그니처** — 프로필 사진, 이름/직함, 소개 문구 포함 가능, 위치·간격·배경 설정

### 관리
- **대시보드** — 발송 캠페인 수, 성공/실패, 성공률, 7/30/90일 추이 차트
- **발송 이력** — 상태/날짜 필터, 서버사이드 정렬, 오픈율/클릭율 조회, 재발송/취소/삭제
- **수신 거부 관리** — HMAC 서명 기반 수신거부 링크, 이름/이메일 검색, CSV 내보내기
- **관리자 알림** — 발송 완료 시 성공/실패 통계를 이메일로 전송

### 개발/테스트
- **드라이런 모드** — 실제 발송 없이 동작 테스트
- **디버그 모드** — 상세 정보 error_log 기록
- **테스트 발송** — 설정 페이지에서 특정 이메일로 즉시 테스트 발송

## 사용법

### 포스트 작성

포스트 편집 화면의 **뉴스레터 발송 설정** 메타박스에서:

1. **뉴스레터로 발송** 체크박스를 활성화합니다.
2. 수신 대상 태그 또는 리스트를 선택합니다 (예상 수신자 수 자동 표시).
3. 발송 모드를 선택합니다:
   - **즉시 발송** — 포스트 발행과 동시에 자동 발송
   - **수동 발송** — 발행 후 관리자가 이력 페이지에서 직접 트리거
   - **예약 발송** — 지정 일시에 자동 발송

### 발송 이력

관리자 메뉴 → 뉴스레터 → 발송 이력

- 상태별 필터(완료/실패/대기 등) + 날짜 범위 필터 + 제목 검색
- 발송 중인 경우 실시간 진행률 표시
- 개별 캠페인 상세: 수신자 목록, 오픈/클릭 이벤트, 실패 원인
- 재발송 / 즉시 발송 / 취소 / 삭제

### 수신 거부 관리

관리자 메뉴 → 뉴스레터 → 수신 거부

- 이름 또는 이메일로 검색
- 직접 추가 / 개별·일괄 해제
- CSV 내보내기

## 트러블슈팅

### 뉴스레터가 발송되지 않음

1. **이력 페이지 확인** — 상태가 "발송 대기"인 채로 오래 머물러 있으면 Cron 지연 의심
2. **관리자 경고 배너** — 대시보드/이력/설정 페이지에 "Cron이 N분 동안 실행되지 않았습니다" 배너가 표시되면 서버 Cron 설정 필요 ([서버 Cron 설정](#5단계--서버-cron-설정-권장) 참고)
3. **즉시 발송 버튼** — 이력 페이지에서 해당 캠페인의 ▶ 버튼으로 즉시 발송 가능

### 이메일이 스팸함으로 분류됨

1. FluentSMTP를 설치하고 SPF/DKIM 설정을 완료하세요.
2. 발신자 이메일 주소가 도메인과 일치하는지 확인하세요.
3. 드라이런 모드가 비활성화되어 있는지 확인하세요.

### 플러그인 활성화 오류

- "필수 플러그인 FluentCRM이 활성화되어 있어야 합니다" → FluentCRM 먼저 설치 후 다시 활성화
- DB 테이블 생성 오류 → WordPress 관리자 계정에 DB 생성 권한이 있는지 확인

### 업데이트 알림이 표시되지 않음

이 플러그인은 GitHub Releases에서 업데이트를 확인합니다. WordPress 관리자 → 플러그인 페이지에서 자동으로 최신 버전 알림을 받습니다. 방화벽으로 `github.com` 접근이 차단된 경우 ZIP을 수동으로 다운로드해 업로드하세요.

## 데이터베이스 테이블

플러그인 활성화 시 아래 테이블이 자동 생성됩니다.

| 테이블 | 설명 |
|--------|------|
| `crmbiz_newsletters` | 뉴스레터 발송 레코드 |
| `crmbiz_nl_queue` | 발송 대기 큐 |
| `crmbiz_nl_sends` | 개별 수신자 발송 로그 |
| `crmbiz_nl_unsubscribers` | 수신거부 목록 |
| `crmbiz_nl_events` | 오픈/클릭/수신거부 이벤트 로그 (90일 보관) |
| `crmbiz_nl_ratelimit` | Rate Limit 카운터 |
| `crmbiz_nl_logs` | 시스템 로그 (7일 보관) |

플러그인 삭제 시 모든 테이블, 옵션, 포스트 메타, 예약 이벤트가 자동 삭제됩니다.
